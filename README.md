# 企业 AI 落地成熟度评估工具

单文件、零依赖的纯前端评估工具，帮助企业快速定位 AI 落地所处阶段。

## 功能

- **6 维度 × 4 问题（24 题）**：战略与治理 / 数据基础 / 技术与平台 / 业务场景 / 组织与人才 / 运营与度量
- **即时评分**：综合成熟度（0–100）与等级（L1 观望 → L5 引领）
- **六维雷达图**：Canvas 手绘，无外部依赖
- **维度分析与改进建议**：短板识别 + 定制化建议
- **90 天行动计划**：按最低分维度生成行动项
- **报告导出**：一键复制或下载 Markdown 报告
- **本地计算**：数据不出浏览器，无需后端

## 使用

直接打开 `index.html`，或部署到任意静态托管（GitHub Pages / Vercel / Netlify / Cloudflare Pages 均可）。

## 技术

- 纯 HTML + CSS + JavaScript，无构建步骤、无 CDN 依赖
- 响应式布局，桌面与移动端可用
